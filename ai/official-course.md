## In brief

- The catch-up course (corso di riallineamento) is called **“OFA Matematica”** (OFA: additional learning requirement, *obbligo formativo aggiuntivo*) and is on [www.ofa.unito.it](https://www.ofa.unito.it/course/view.php?id=20) (course number 20). You log in with your UniTo SCU credentials and enrol yourself, with no enrolment key.
- It has **8 modules**, divided into numbered **units** (1.1, 1.2, 2.1, …). For each unit there is a **Libro** (book), almost always an interactive **“Esplora”** (explore) worksheet, often a page of **Applicazioni** (applications), **Esercizi** and **Soluzioni** (exercises and solutions) as PDFs and an online **Test**; at the end of each module there is an **end-of-module test**.
- The test questions are based on **all the course material**: the notes in this guide follow the same modules and the same units, but they do not replace it.
- The material contains a few **typos**: you will find them at the bottom of this page, already verified. The notes have the correct version.

## The activities of each unit

| Activity | What it is | How to use it |
|---|---|---|
| Libro | the theory of the unit, divided into chapters, with worked examples | read it after the notes on the same topic, to get used to the course notation |
| Esplora | an interactive Maple worksheet, with graphs and calculations on the topic of the unit | use it to see what happens when a coefficient changes |
| Applicazioni | a page or a PDF with a real-world problem solved with the maths of the unit | read it as an extra worked example |
| Esercizi and Soluzioni | two PDFs: first the exercises, then the solutions (often just the result) | do them all by hand and check at the end |
| Test | an online test (Maple T.A.) on the unit; at the end of the module there is the end-of-module test | redo it until you get through it with no mistakes |

The book shows the formulas as images: if a formula is hard to read, zoom in on the page.

## The course notation

The notes use the same notation, so there are no surprises in the test:

- trigonometric functions $\sin x$, $\cos x$, $\tan x$ and $\operatorname{cotan} x$; natural logarithm $\ln x$, logarithm to base $a$ $\log_a x$;
- intervals with round brackets (endpoint excluded) and square brackets (endpoint included): $(-2, 3]$, $(-\infty, 1)$;
- in solutions: $\forall x \in \R$ (every real number), $\nexists x \in \R$ (no solution), $\vee$ for “or” (oppure); “t.c.” for “such that” (tale che);
- in trigonometry exercises the general solutions are written with $k \in \Z$, for example $x = \frac{\pi}{4} + k\pi$.

## Typos in the material

Recalculating the course exercises to write the notes turned up a few typos. Each one was double-checked with symbolic computation and **compared with the original page or PDF** on 30 September 2026. The notes have the correct version. The list only includes the verified typos and is not a complete review of the material; in module 3 none were found. If you find others you can report them to the [platform helpdesk](https://www.ofa.unito.it/helpdesk/index.php?t=tcre).

### Module 1

- **Libro 1.1**, proof by contradiction that if $n^2$ is even then $n$ is even: with $n = 2p + 1$ we get $n^2 = 4p^2 + 4p + 1$, not $4p^2 + 2p + 1$. The conclusion ($n^2$ is odd) is still correct.
- **Libro 1.1**, example on how to state a theorem: two real numbers with the same absolute value are equal **or** opposite ($a = b$ or $a = -b$), not “equal and opposite” (uguali ed opposti).
- **Libro 1.2**, extension from $\Z$ to $\Q$: the equation $ax = b$ has the solution $x = \frac{b}{a}$ when $a \ne 0$; the book writes $b \ne 0$.
- **Soluzioni 1.1, exercise 2**, items iv and v: the negation of “all children are more than 6 years old” is “at least one child is **at most** 6 years old”, not “less than 6 years old” (a child of exactly 6 makes the original sentence false). In the same way, the negation of “there is a building with more than 10 floors” is “every building has at most 10 floors”.
- **Soluzioni 1.2, exercise 1**: the largest four-digit number in which units plus tens equals hundreds plus thousands is $9999$ ($9 + 9 = 9 + 9$), not $9054$. Even requiring all the digits to be different, there are numbers larger than $9054$, for example $9687$.
- **Soluzioni 1.2, exercise 5**: $\frac{27}{8}$ is not equal to $\frac{9}{2}$; an equivalent fraction is $\frac{27}{6}$.

### Module 2

- **Libro 2.1**, taking out the common factor: $15x^3 + 3x^2 - 6x = 3x(5x^2 + x - 2)$, not $3x(5x^3 + x^2 - 2)$.
- **Soluzioni 2.1, exercise 3**: $(2x^3 - 10x^2 + 3x - 15) : (x - 5)$ gives the quotient $2x^2 + 3$ (remainder $0$), not $2x^3 + 3$.
- **Soluzioni 2.1, exercise 6**: $8x^3 + 36x^2 + 54x + 27 = (2x + 3)^3$, not $(2x + 3)^2$: the text itself talks about the cube of a binomial.

### Module 4

- **Libro 4.3, example 4** ($|x + 1| + |x - 2| \le 5$): the first system gives $-2 \le x < -1$, not $-2 \le x < 1$. The final result, $-2 \le x \le 3$, is correct.
- **Soluzioni 4.2, exercise 6** ($\sqrt{7x + 2} + \sqrt{16 - x^2} > -5$): the solution is the domain, $-\frac{2}{7} \le x \le 4$, not “for every real $x$”. The reasoning on the sheet (a sum of square roots is never negative) is correct, but it only holds where the roots exist.

### Module 5

- **Libro 5.2**, circle, tangent line to $x^2 + y^2 + 6x - 4y = 0$ at the point $P_0 = (-6, 4)$: the line through $P_0$ with slope $\frac{3}{2}$ is written $y - 4 = \frac{3}{2}(x + 6)$. The book writes $y - 2 = \frac{3}{2}(x + 3)$, which passes through the centre $(-3, 2)$; the final result, $y = \frac{3}{2}x + 13$, is correct.

### Module 6

- **Libro 6.1**, translations: $\cos\left(\frac{x}{2} + 1\right)$ is obtained from $\cos\frac{x}{2}$ by a translation of **2** units to the left, not one, because $\cos\left(\frac{x}{2} + 1\right) = \cos\frac{x + 2}{2}$. In the same way, $\cos\left(\frac{x}{2} - 1\right)$ is shifted 2 units to the right. The vertical shifts ($\pm 1$) are correct.
- **Soluzioni 6.1, exercise 1**: the domain of $f(x) = \sqrt{2x^2 - x - 3}$ is $x \le -1$ or $x \ge \frac{3}{2}$, not $x \le 1$ or $x \ge \frac{3}{2}$.

### Module 7

- **Soluzioni 7.2, exercise 6** ($\left(\frac{1}{3}\right)^{x^2 - 1} < 9^{2x}$): the solution is $x < -2 - \sqrt{5}$ or $x > -2 + \sqrt{5}$. The sheet writes $x < -1 - \sqrt{5}$ in the first part; the second is correct.

### Module 8

- **Libro 8.2**, inequalities, example 2 ($\cos 2x < 1$ in $[0, 2\pi]$): $\cos 2x = 1$ when $2x$ equals $0$, $2\pi$ or $4\pi$, i.e. for $x = 0$, $x = \pi$ and $x = 2\pi$. The solution is $0 < x < \pi$ or $\pi < x < 2\pi$; the book only excludes $0$ and $2\pi$.
- **Soluzioni 8.2, exercise 10** ($\tan x \ge 1$ in $[0, 2\pi]$): the solution is $\frac{\pi}{4} \le x < \frac{\pi}{2}$ or $\frac{5}{4}\pi \le x < \frac{3}{2}\pi$. The one on the sheet ($0 \le x < \frac{\pi}{2}$, $\frac{3}{4}\pi \le x < \frac{3}{2}\pi$, $\frac{7}{4}\pi \le x \le 2\pi$) is the solution of $\tan x \ge -1$.
